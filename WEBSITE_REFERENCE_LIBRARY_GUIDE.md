# Website Design Reference Library

This library turns inspiring websites into reusable design and build knowledge.

## Capture workflow

For each reference site:

1. Record the URL, date reviewed, category, and a one-sentence creative thesis.
2. Map the page into major scenes: loading, hero, navigation, content chapters, conversion moments, and footer.
3. Document the visual system: type, palette, imagery, grid, spacing, UI treatment, and brand details.
4. Observe motion by scrolling slowly on desktop and mobile. Note triggers, timing, scroll behavior, pinned scenes, parallax, masks, and interaction feedback.
5. Identify the likely technical approach only when it is observable: for example GSAP, ScrollTrigger, Lenis, CSS transitions, Lottie, video, or WebGL.
6. Extract reusable principles and implementation recipes; do not copy another brand's content, assets, or distinctive identity.

## Naming convention

Use this pattern for reference files:

`YYYY-MM — Site Name — Focus.md`

Example: `2026-09 — ERA Residence — Cinematic Scroll.md`

## Quality bar

A useful reference describes both **what happens** and **why it feels effective**. Separate observed facts from inferred implementation details, include reduced-motion considerations, and finish with a practical adaptation plan.
